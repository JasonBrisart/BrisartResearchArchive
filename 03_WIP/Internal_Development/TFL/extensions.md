# Historical Context

This document records proposed additions, modifications, or expansions to the developing model.

Purpose:

As new observations emerged, it became necessary to explore whether the existing structure adequately explained them.

The extensions recorded here represent attempts to solve specific developmental problems.

Historical Importance:

Many framework ideas never become visible because they are discarded before publication.

This file preserves those exploratory ideas for historical and archival purposes.

Relationship To Released TFL:

The majority of proposals contained here should be viewed as developmental possibilities rather than official framework elements.

## Persistence

- Introduce explicit persistence threshold parameters into the model rather than assuming continuous scaling.
- Incorporate persistence inertia as a state variable independent of E(t).
- Introduce secondary drivers of persistence beyond affective intensity.

## Belief & contradiction

- Formalize belief as a weighting function that modulates both retrieval and contradiction processing.
- Define belief as an emergent property of repeated high-persistence simulations.
- Model asymmetric update dynamics for confirmation vs contradiction.

## Reentry & cue overlap

- Add a cue-overlap parameter governing reentry probability.
- Extend reentry mechanisms to include both affective intensity and contextual similarity.

## Simulation dynamics

- Introduce latent simulation states that persist below conscious reporting thresholds.
- Add multi-simulation competition dynamics with defined resolution mechanisms.
- Introduce oscillatory or switching dynamics for competing simulations.
- Differentiate internally and externally generated simulations at the structural level.

## Memory & retrieval

- Extend affect modeling to include influence on memory retrieval selection.
- Model memory retrieval as a function conditioned on active simulation state.

## General modeling

- Add adaptive weighting between Input(t) and Sim(t) based on uncertainty.
- Implement discrete state transition rules for resolution events.
- Prioritize behavioral output as the primary observable for simulation strength.
- Introduce learning dynamics that modify thresholds over repeated exposure.
- Incorporate nonlinear interaction terms between belief and affect.
