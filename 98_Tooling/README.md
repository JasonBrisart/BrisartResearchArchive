# 98_Tooling

**Python applications, utilities, and development tooling used across the Brisart Research Archive.**

98_Tooling is the software tooling and application layer of the Brisart Research Archive. It contains standalone programs designed to support research, engineering, security, documentation, testing, distribution, project management, and day-to-day operational workflows.

Projects may range from focused utilities to complete end-user applications. They remain separate from the Archive's research frameworks, operating-system development, native APIs, and shared foundational components such as encryption.

## Project Principles

Projects within 98_Tooling emphasize:

- Minimal dependencies
- Clear ownership and maintainable architecture
- Reproducible and offline-capable workflows
- Cross-project interoperability where appropriate
- Practical day-to-day value
- Stable, testable behavior
- Clear separation from shared foundational infrastructure
