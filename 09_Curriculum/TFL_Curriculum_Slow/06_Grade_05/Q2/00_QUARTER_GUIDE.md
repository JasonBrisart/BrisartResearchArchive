## The pivot lesson of this quarter

**Lesson 13 — Stronger Contradictions.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Lesson 9:** every student has a completed nine-card tally
- **Lesson 10:** every student classifies at least six correctly
- **Lesson 11:** the class has a pooled number greater than one
- **Lesson 12:** every student writes both explanations and admits the question is open
- **Lesson 13:** every student records both counts
- **Lesson 14:** every student classifies three real cases
- **Lesson 15:** every student has three logged entries with outcomes
- **Lesson 16:** the class rejects the deleted category with reasons

## Errors to expect this quarter

| Lesson | Students will | Correct it by |
|---|---|---|
| 9 | revise after seeing the card | Collect written expectations face-down before each reveal. |
| 10 | add deleted as a fourth category | Ask for the evidence: show me one that was gone instantly and never came back. |
| 11 | report the predicted number rather than the measured one | Require the tally sheet with the number. |
| 12 | pick one confidently | Ask what they would measure to tell them apart. |
| 13 | run only one condition | Require both, in the same session, same pattern. |
| 14 | report the event without the outcome | Require the classification for every entry. |
| 15 | backfill the log later | Date-stamp entries in class weekly. |
| 16 | reintroduce instant deletion | Point at the recovery data every time. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
