## The pivot module of this quarter

**Module 2 — Testing The Disclosure.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Module 1:** every protocol has verbatim wording and a named role per context
- **Module 2:** every protocol is delivered by somebody who did not write it
- **Module 3:** every plan states what transfers if the student redirects

## Errors to expect this quarter

| Module | Students will | Correct it by |
|---|---|---|
| 1 | write guidance rather than wording | Require verbatim text: write the sentence. |
| 2 | coach the deliverer | No verbal support. Enforce it. |
| 3 | write an exit path that loses accumulated work | Require transfer: what survives redirection? |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
