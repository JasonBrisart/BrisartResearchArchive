# Vocabulary Reference

Student-facing language by band, with the framework terms each one maps to.

## Master Mapping

| Framework term | Band A/B name | Band C/D name | Meaning |
|---|---|---|---|
| `Input(t)` | What I notice | Sensory input | What is coming in right now |
| `Minfo(t)` | What I remember | Retrieved memory | What comes back from before |
| `Sim(t)` | What I expect | Predictive simulation | The predicted or inferred outcome |
| `E(t)` | How much it matters | Affective intensity | How strongly it sticks; governs persistence |
| `F(t)` | Right now | Integrated state | Everything combined into this moment |
| `Belief(t)` | What I already think | Belief constraint | A stable prior that biases memory and prediction |

## Band A (K-2) — Four Words Only

- **Notice** — what I see, hear, or feel right now
- **Remember** — what comes back from before
- **Expect** — what I think happens next
- **Surprise** — when what happened was not what I expected

Do not introduce any other terms in Band A.

## Band B (3-5) — Adds Two

Everything from Band A, plus:

- **Right now** — everything put together into this moment
- **Carry forward** — right now becomes the start of what comes next

## Band C (6-8) — Formal Names

Everything above, plus:

- **`Input(t)`** — sensory evidence available in the current window
- **`Minfo(t)`** — retrieved memory content active in the window
- **`Sim(t)`** — the predictive simulation; must be identifiable, meaning students can state its content
- **`E(t)`** — affective intensity; decides carry-over only
- **`F(t)`** — the integrated state, carried forward as a prior
- **Temporal window** — a processing step of roughly 100 to 300 milliseconds
- **Persistence** — a simulation continuing across windows
- **Decay** — a simulation weakening and not carrying forward
- **Recurrence** — previously seen simulation content reappearing
- **Contradiction** — mismatch between `Sim(t)` and `Input(t)` that drives update
- **Resolution** — a simulation ending or transforming

## Band D (9-12) — Formal System

Everything above, plus:

- **Integration function** — `F(t) = w1·Input(t) + w2·Minfo(t) + w3·Sim(t)`
- **Integration weights** — `w1`, `w2`, `w3`; relative contribution of input, memory, simulation
- **Persistence condition** — `Sim(t+1) = Sim(t), if E(t) > θ_persistence`
- **Persistence threshold** — `θ_persistence`; the affective level required for carry-over
- **Propagation** — carrying `F(t)` and surviving simulations into the next window
- **Prior** — a state or constraint from an earlier cycle that shapes the current one
- **Adjudication** — comparing TFL against alternative explanations
- **Falsification condition** — the result that would count against the model

## Terms to Avoid in All Bands

| Avoid | Reason |
|---|---|
| Consciousness | TFL does not claim to explain it |
| Subconscious / unconscious | Not part of the framework |
| Trauma, anxiety, disorder | Not a clinical model |
| Brain region names | Not a neural implementation |
| Personality, identity | Outside the modeled scope |
