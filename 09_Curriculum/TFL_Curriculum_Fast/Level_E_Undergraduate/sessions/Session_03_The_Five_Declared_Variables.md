# Level E — Session 3: The Five Declared Variables

**Duration:** 75 min

## Objective

Students map plain-language description onto formal notation and state the exclusive gating constraint.

---

## 1. Frame — Naming Without Adding (8 min)

**Say:**
> "Notation is not content. Everything we name today you already experienced in Session 2. The reason to formalize is that vague terms cannot be measured and unmeasurable claims cannot be wrong."

---

## 2. Build — The Declared Set (25 min)

Build the table on the board. Plain name first, formal name second.

| What you said | Formal | What it is |
|---|---|---|
| What's coming in | `Input(t)` | Sensory evidence in the current window |
| What came back | `Minfo(t)` | Retrieved memory content active in the window |
| What I figured would happen | `Sim(t)` | The predictive simulation |
| How much it hit me | `E(t)` | Affective intensity |
| The whole moment | `F(t)` | The integrated state |

Explain `(t)` once: a value at this time step, different at the next.

Introduce `Belief(t)` as a sixth term with different status:

> "An affectively stabilized structural prior that constrains retrieval and simulation under ambiguity. It's a constraint across cycles rather than a signal within one. That distinction matters when we get to closure in Session 10."

**State the gating constraint now, not later:**

> "`E(t)` does not help build the prediction. It functions exclusively as a persistence gate — it decides whether a simulation survives into the next window. Write that down. Nearly every misreading of this framework comes from ignoring it."

---

## 3. Contest — Is This Set Complete? (20 min)

**Say:**
> "Propose a sixth variable that would improve the model."

Students propose: attention, motivation, confidence, fatigue, arousal, context.

Write them all. Then for each:

> "Can it be expressed through the declared five? If not, what would adding it cost?"

Attention is the productive case — partially absorbable as what gets sampled into `Input(t)`, not fully.

**Say:**
> "Hold the cost question. Session 10 answers it, and the answer is that a model you can extend whenever it fails can never fail."

---

## 4. Apply — Component Mapping (17 min)

Students map three real moments to all five components.

    Moment:
    Input(t):
    Minfo(t):
    Sim(t):
    E(t):        high / medium / low
    F(t):

**Requirement:** each `Sim(t)` must be specific enough that a third party could check whether it occurred.

**Circulate.** Reject mood-states in the `Sim(t)` line. "I felt uneasy" is not a simulation. Push for content.

---

## 5. Propagate (5 min)

**Say:**
> "Next: how fast this runs, and why the number is more contestable than it looks."

---

## Instructor Notes

- Introduce notation once and then use it relentlessly. Undergraduates adapt within one session if the instructor does not code-switch back to plain language.
- The `E(t)` constraint stated here prevents most Level E misconceptions. Delaying it to Session 7 is a common instructional error.
