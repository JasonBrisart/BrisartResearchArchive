# Micro-Lesson C2: The Four-Box

**Duration:** 8 minutes
**Band:** C (6-8)
**Materials:** Board

---

## Purpose

Demonstrate that persistence and accuracy are independent, using live class data.

## Script

Draw the matrix:

```
                  PERSISTED        FADED
    ACCURATE    [           ]   [           ]
    INACCURATE  [           ]   [           ]
```

**Say:**
> "Give me one prediction each. Tell me which box."

Fill all four with real examples. All four will fill.

**Then the argument:**

> "If `E(t)` tracked accuracy, which boxes would be empty?"

Answer: accurate-faded and inaccurate-persisted.

> "Are they?"

No.

**Close:**
> "`E(t)` gates persistence. It says nothing about accuracy. Your own data just showed it."

## The Strongest Box

Point at **inaccurate-persisted** specifically.

> "This box is the whole argument. These were wrong and they stuck anyway."

## Use

Essential before Quiz 2 and the unit test. Best single re-teach if either goes badly.
