# Band C — Day 7: Recurrence

**Duration:** 45 min
**Materials:** Notebooks

---

## Objective

Students define recurrence and distinguish it from continuous persistence.

---

## 1. Quiz 2 (10 min)

Administer Quiz 2.

---

## 2. Hook — The Return (5 min)

**Say:**
> "Yesterday the square broke your prediction. Then circles came back and so did your prediction. Was that prediction running the whole time in between?"

Let them argue. Both positions are defensible, which is the point.

---

## 3. Name — Recurrence (10 min)

Write:

```
RECURRENCE
The reappearance of previously identified
simulation content across temporal windows.

PERSISTENCE — it carried forward continuously
RECURRENCE  — it came back after being absent
```

**Say:**
> "These are different. Something can persist across every window. Or it can drop out and reappear later. Both are in the model."

---

## 4. Work — Tracking Recurrence (16 min)

Students track one prediction across a full day using a window-sampling log.

| Check-in time | Was the prediction active? | Y / N |
|---|---|---|
| Morning | | |
| Mid-morning | | |
| Lunch | | |
| Afternoon | | |
| End of day | | |

Students use yesterday's data or reconstruct from memory, then classify:

```
Pattern observed:
  [ ] Persistent  (active at every check-in)
  [ ] Recurrent   (dropped out, came back)
  [ ] Resolved    (active, then gone for good)
```

Then one written question:

> Which pattern was yours, and what was `E(t)` doing?

---

## 5. Compare — Three Patterns (4 min)

Collect one example of each pattern.

**Say:**
> "Three different shapes over time from the same system. Next session we name what makes each shape happen."

## Instructor Notes

- Students may argue that recurrence is just persistence you didn't notice. That is a legitimate objection. Credit it and note that distinguishing them requires measurement — which is exactly the Band D problem.
