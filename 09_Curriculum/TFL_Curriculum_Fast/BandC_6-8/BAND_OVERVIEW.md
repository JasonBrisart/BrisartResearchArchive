# Band C Overview — Grades 6-8

**Unit title:** Prediction, Persistence, and Contradiction

**Sessions:** 10
**Session length:** 45 minutes
**Suggested pacing:** Three to four weeks

---

## What Students Learn

Band C introduces the formal variable names and establishes the central distinction of the entire curriculum:

> Affective intensity decides whether a prediction is **carried forward**. It does not decide whether the prediction was **correct**.

Students also learn the temporal window, contradiction, recurrence, and resolution.

## Variables Introduced

| Variable | Name | Plain meaning |
|---|---|---|
| `Input(t)` | Sensory input | Sensory evidence in the current window |
| `Minfo(t)` | Retrieved memory | Memory content active in the window |
| `Sim(t)` | Predictive simulation | The specific predicted outcome |
| `E(t)` | Affective intensity | How strongly it matters; governs carry-over only |
| `F(t)` | Integrated state | All of it combined into the current moment |
| `Belief(t)` | Belief constraint | A stable prior that biases memory and prediction |

**Critical constraint students must learn:** `E(t)` does not build the prediction. It only gates whether the prediction persists.

## Session Arc

| Day | Title | Core move |
|---|---|---|
| 1 | Naming the System | Plain language to formal variables |
| 2 | The Temporal Window | 100-300 ms; update rate vs. content duration |
| 3 | Simulation Must Be Identifiable | If you can't state it, it isn't `Sim(t)` |
| 4 | Persistence and the Threshold | `E(t)` as a gate |
| 5 | Persistence Is Not Accuracy | The central distinction |
| 6 | Contradiction | What mismatch actually does |
| 7 | Recurrence | Why broken predictions return |
| 8 | Belief as a Prior | Stable structure biasing retrieval |
| 9 | System Dynamics | Rapid resolution, sustained recurrence, escalation |
| 10 | Scope and Assembly | What TFL does not model; unit test |

Day 5 is the pivot. Days 9 and 10 prepare students for Band D.

## Prerequisites

None required. If students completed Band B, Day 1 can be compressed and time moved to Day 5.

## Assessment Summary

| Instrument | Weight |
|---|---|
| Homework sets (4) | 25% |
| Quiz 1 — variables and window | 10% |
| Quiz 2 — persistence and contradiction | 15% |
| Unit test | 50% |

## Standing Rules

1. Prediction accuracy is never graded.
2. Over-applying the framework is a scored error, not enthusiasm.
3. `E(t)` is affect as intensity only. Keep examples low-stakes. See `SCOPE_AND_BOUNDARIES.md`.
