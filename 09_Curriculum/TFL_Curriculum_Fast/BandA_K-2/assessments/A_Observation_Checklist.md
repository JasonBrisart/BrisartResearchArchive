# Band A Observation Checklist

Band A uses observation rather than written testing. Complete one row per student across the unit.

---

## How to Use

- Observe during normal activities. Do not create a testing situation.
- Mark on any day the behavior is observed. Students do not need to demonstrate on a specific day.
- Two marks in a column is sufficient evidence.

## Observation Prompts

If a student has not demonstrated a column naturally, prompt directly during an activity:

| Column | Prompt |
|---|---|
| Noticed | "Tell me one thing you notice right now." |
| Remembered | "What happened right before this?" |
| Expectation | "What do you think happens next?" |
| Surprise | "Were you surprised? What did you think was coming?" |
| Cycle | "After that, does it start over or does it stop?" |

## Scoring

| Marks | Level |
|---|---|
| 5 columns | Secure |
| 3-4 columns | Developing |
| 0-2 columns | Needs revisiting |

Students at "needs revisiting" should repeat Micro-Lessons A1 and A3 before moving to Band B.

## What Is Not Assessed

- Whether predictions were correct
- Vocabulary precision
- Writing or drawing quality
- Speed of response
