# Band D — Day 7: Operationalization

**Duration:** 50 min

---

## Objective

Students link each variable and parameter to a measurable observable.

---

## 1. Hook — The Unmeasurable Study (7 min)

Present a flawed proposal:

> "We'll measure whether students' simulations persist by asking them at the end of the week if they felt like their predictions stuck around."

**Ask:**
> "What's wrong with this?"

Students should identify: `Sim(t)` content never specified, `E(t)` never measured, no defined window, no persistence criterion.

**Say:**
> "This isn't a weak TFL study. It isn't a TFL study at all."

---

## 2. Name — The Testability Constraint (12 min)

Write it:

```
TESTABILITY CONSTRAINT

TFL applies only where all core variables can be
operationalized and measured.

Any use of the framework without observable mapping
of Input(t), Minfo(t), E(t), Sim(t), and F(t) does
not constitute a valid application or test of TFL.
```

**Say:**
> "That's a strong statement. It means most casual uses of this framework are invalid by the framework's own standard."

Add the parameter requirement:

> "Parameters must be linked to observable quantities in valid implementations. A weight you cannot connect to data is not a parameter — it's decoration."

---

## 3. Work — Build the Measurement Map (20 min)

Students specify observables for a study of their choosing.

```
STUDY TOPIC: _____________________________

Input(t)    → measured by: ________________
Minfo(t)    → measured by: ________________
Sim(t)      → measured by: ________________
              (must be stateable and checkable)
E(t)        → measured by: ________________
F(t)        → measured by: ________________

θ_persistence → defined as: _______________
Window length → defined as: _______________
```

**Standard to enforce:** Could another person run this without asking you what you meant?

---

## 4. Compare — Peer Audit (9 min)

Students exchange maps and audit.

**Audit questions:**
1. Is `Sim(t)` stateable and checkable?
2. Is `E(t)` measured or assumed?
3. Is the persistence criterion defined in advance?

Return with written feedback on each.

---

## 5. Carry (2 min)

**Say:**
> "You can now measure it. Tomorrow: three other explanations that would produce the same data."
