# Micro-Lesson D5: Scope Rejection

**Duration:** 7 minutes
**Band:** D (9-12)

---

## Purpose

Practice formal rejection of invalid applications.

## Script

Read proposals. Students state VALID or INVALID **plus the boundary violated**.

| Proposal | Answer |
|---|---|
| Tracking stated expectations across a 15-minute task | VALID |
| Explaining why someone became more outgoing over four years | INVALID — developmental trajectory |
| Testing whether contradicting feedback revises a stated prediction | VALID |
| Identifying which students have anxiety | INVALID — not a clinical model; no diagnostic content |
| Explaining why a crowd reacts as a unit | INVALID — group-level dynamics |
| Locating which brain region generates `Sim(t)` | INVALID — not a neural implementation |
| Measuring recurrence of a stated expectation across a class period | VALID |

## The Required Form

Rejection must name the boundary, not just express doubt:

```
INVALID because the framework is not defined to model
[specific exclusion], which operates at [different
timescale / level of analysis].
```

## The Clinical Case

Spend extra time on the anxiety proposal.

**Say:**
> "This one isn't merely out of scope. The framework provides no diagnostic criteria or therapeutic mechanisms, and using it that way is a misuse — not an extension."

## Use

Before Day 11 and the final, where invalid-application identification is a gate requirement.
