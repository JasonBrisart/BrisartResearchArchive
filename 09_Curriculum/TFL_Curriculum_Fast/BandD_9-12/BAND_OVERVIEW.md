# Band D Overview — Grades 9-12

**Unit title:** TFL as a Formal System

**Sessions:** 12
**Session length:** 50 minutes
**Suggested pacing:** Four to six weeks

---

## What Students Learn

Band D treats TFL as a formally specified, testable system. Students work directly with the integration function and persistence condition, reason about parameter changes, design a study, and state a falsification condition.

The band's defining outcome: **students must be able to argue against the framework as competently as they argue for it.**

## The Formal Content

```
F(t) = w1·Input(t) + w2·Minfo(t) + w3·Sim(t)

Sim(t+1) = Sim(t),  if  E(t) > θ_persistence
```

Students must be able to explain why `E(t)` appears in the second relation and not the first.

## Session Arc

| Day | Title | Core move |
|---|---|---|
| 1 | The Declared Variable Set | Closure — nothing beyond five variables |
| 2 | The Integration Function | Reading and using the relation |
| 3 | Weights and Behavior | Reasoning about parameter change |
| 4 | The Persistence Gate | Why `E(t)` is structurally separate |
| 5 | Loop Tracing | Hand-tracing multiple cycles |
| 6 | Guarantees | What the architecture commits to |
| 7 | Operationalization | Linking parameters to observables |
| 8 | Alternative Explanations | Uncertainty, arousal, habit |
| 9 | Adjudication | Designing to distinguish |
| 10 | Falsification | Stating what would count against |
| 11 | Scope and Invalid Application | Rejection as a skill |
| 12 | Final Assessment | Study design and defense |

## Prerequisites

Band C is strongly recommended. Students entering cold should complete Micro-Lessons C1-C4 first.

## Assessment Summary

| Instrument | Weight |
|---|---|
| Homework sets (5) | 20% |
| Quizzes (3) | 15% |
| Midterm — trace and structure | 25% |
| Final — design, falsification, scope | 40% |

**Gate requirement:** The final requires a stated falsification condition and a correctly identified invalid application. Both are required to pass the final regardless of other scores.

## Standing Rules

1. Prediction accuracy is never graded.
2. A study built on an unmeasurable `Sim(t)` is not a valid TFL study.
3. Over-application is a scored error.
4. Keep affect low-stakes. TFL is not a clinical model and no assessment may frame it as one.
