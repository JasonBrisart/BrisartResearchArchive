# Band B — Day 3: Carry Forward

**Duration:** 35-40 min
**Materials:** Chart paper

---

## Objective

Students understand that each moment begins with what the previous moment handed it.

**This is the hardest concept in Band B. Budget the full session.**

---

## 1. Hook — The Reset Question (5 min)

**Say:**
> "Here's a question. When one moment ends and the next one starts — does your brain start over from nothing?"

Take a vote. Many students will say yes.

**Say:**
> "Let's test it."

**Say:**
> "Think about a purple elephant."

Pause three seconds.

**Say:**
> "Now think about anything you want."

**Ask:**
> "How many of you are still thinking about the elephant?"

Most hands.

**Say:**
> "You were told to start fresh. You didn't. The last moment came with you."

---

## 2. Name — Carry Forward (8 min)

Write **CARRY FORWARD** on the chart.

Extend the Day 2 diagram:

```
   NOTICE   ─┐
   REMEMBER ─┼──→  RIGHT NOW ──┐
   EXPECT   ─┘                  │
        ↑                       │
        └───────────────────────┘
              carried forward
```

**Say:**
> "Right now doesn't disappear. It becomes the starting point for the next one."

**Say the key line:**
> "Nothing starts from zero. Every moment begins with what the last one handed it."

Write that sentence on the chart. Leave it up for the rest of the unit.

---

## 3. Work — The Inheritance Trace (16 min)

Students trace one thing across four moments.

**Template:**

| Moment | What was carried in from before | What I noticed | What I expected next |
|---|---|---|---|
| 1 | (nothing / starting point) | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

**The rule that makes this work:** Column 2 of each row must contain something from the previous row. If a row's inheritance column is blank or unrelated, the trace is broken.

**Model one first** using something that happened this morning.

**Circulate and check column 2 only.** That is where the learning is.

---

## 4. Compare — Find the Broken Chain (8 min)

Put an intentionally broken trace on the board — one where row 3 inherits nothing from row 2.

**Ask:**
> "What's wrong with this one?"

Let students find it.

**Say:**
> "Row three started from nothing. That's the one thing that can't happen."

---

## 5. Carry — Forward (3 min)

**Say:**
> "Tomorrow we're going to do this with our bodies instead of on paper, and you'll feel how much work carrying forward actually takes."

---

## Assessment

Administer **Quiz 1** at the start of Day 4, or at the end of this session if time allows.

## Instructor Notes

- The purple elephant demonstration is reliable. Use it exactly as written.
- Expect students to write traces where each row is independent. This is the predicted error. The fix is always the same: point at column 2 and ask "where did that come from?"
