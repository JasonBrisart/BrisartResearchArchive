# Band B — Day 8: The Whole Loop

**Duration:** 35-40 min
**Materials:** Chart paper, unit task handout

---

## Objective

Students assemble all five parts into a complete loop and complete the unit task.

---

## 1. Hook — Build It From Memory (6 min)

**Say:**
> "Notebooks closed. Someone give me the first part."

Build the full diagram on the board entirely from student contributions. Do not supply anything yourself.

Target:

```
   NOTICE   ─┐
   REMEMBER ─┼──→  RIGHT NOW ──┐
   EXPECT   ─┘                  │
        ↑                       │
        └───────────────────────┘
              carried forward

   Some of it sticks. Some fades.
```

---

## 2. Name — The Five Ideas (6 min)

Number them on the chart:

```
1. You notice, remember, and expect — constantly.
2. Those combine into right now.
3. Right now carries forward into the next moment.
4. When a guess breaks, it changes — but not instantly.
5. What sticks depends on how much it mattered, not on being right.
```

**Say:**
> "That's the entire unit. Five sentences."

---

## 3. Work — Unit Task (20 min)

Administer the **Unit Task: Loop Trace**.

Students work individually. Circulate but do not supply content.

**Prompts you may give:**
- "Where did that expectation come from?"
- "What did the previous moment hand you?"

**Prompts you may not give:**
- Any suggestion of what to write
- Confirmation that an answer is correct

---

## 4. Compare — One Volunteer Trace (5 min)

With permission, put one completed trace on the board.

**Ask the class:**
> "Find the carry-forward. Show me where moment two starts from moment one."

---

## 5. Carry — Beyond the Unit (3 min)

**Say:**
> "It's running right now. It was running before this unit and it doesn't stop when the unit ends. The only difference is that now you can see it."

---

## End of Band B

Students should be able to name all five parts in plain language, explain that each moment starts from the previous one, describe what contradiction does, and say that sticking depends on how much something mattered.

Band C renames these parts with formal variables and adds the persistence threshold.
