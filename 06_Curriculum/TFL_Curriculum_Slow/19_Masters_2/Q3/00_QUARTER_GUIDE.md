## The pivot session of this quarter

**Session 16 — Adjudication At Review Standard.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Session 13:** every review carries located findings in every section
- **Session 14:** every self-review names at least three serious findings
- **Session 15:** every design is correctly labelled hypothetical or approved
- **Session 16:** every verdict names the failing element
- **Session 17:** the second verdict is better than the first, or the reason is stated
- **Session 18:** every design contains all eight components

## Errors to expect this quarter

| Session | Students will | Correct it by |
|---|---|---|
| 13 | produce verdicts without findings | Return any review with a section carrying only a verdict. |
| 14 | find nothing serious in their own | Require three. There always are. |
| 15 | treat it as administrative | State the consequence plainly. |
| 16 | give verdicts without naming the failing element | Require it every time. |
| 17 | rebuild elements that were not the problem | Require the named failing element to be the one rebuilt. |
| 18 | omit the analysis plan | Check for it explicitly. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
