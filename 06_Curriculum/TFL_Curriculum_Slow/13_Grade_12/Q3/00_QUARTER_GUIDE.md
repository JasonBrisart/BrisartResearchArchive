## The pivot lesson of this quarter

**Lesson 21 — The Inference Ceiling.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Lesson 17:** every student has three correctly ordered arguments
- **Lesson 18:** every claim is narrow enough for one project
- **Lesson 19:** every student demonstrates a pathway rather than asserting one
- **Lesson 20:** every student receives an executability check with unrunnable lines marked
- **Lesson 21:** every student names the rung they will be tempted to claim
- **Lesson 22:** every student states honestly whether a null fires their condition
- **Lesson 23:** every planned analysis is marked in advance
- **Lesson 24:** every student's capstone has all eight parts present

## Errors to expect this quarter

| Lesson | Students will | Correct it by |
|---|---|---|
| 17 | place the condition as a closing caveat | Return it: that is a caveat. First is what makes it a test. |
| 18 | select the whole framework as the target | Narrow it with them until one claim remains. |
| 19 | assert the condition could fire | Require the result: write the actual observations. |
| 20 | write a design requiring their presence | Hand it to a classmate on the spot and list every question asked. |
| 21 | place their ceiling too high | Ask what converging evidence they have. Rung four needs more than one design. |
| 22 | claim a null refutes the framework | Walk the controls: did they hold? If you cannot say, the null is uninformative. |
| 23 | leave analyses unlabelled to decide later | Require labels now: deciding later is exactly the problem. |
| 24 | leave a gate for later | Run the gate check first, before anything else is read. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
