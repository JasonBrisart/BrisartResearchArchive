## Exit outcomes

- Write the integration function and define every term
- State variable closure and give its cost in falsifiability terms
- Explain conditional determinism including its condition
- Write a structural argument costing a proposed modification

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **integration function** | F(t) = w1 Input(t) + w2 Minfo(t) + w3 Sim(t) |
| **integration weights** | w1, w2, w3; relative contribution of the three inputs |
| **conditional determinism** | fixed inputs and parameters yield a unique F(t) |
| **variable closure** | all valid inferences restricted to the declared five |
| **parameter** | a value that shapes behaviour and must link to an observable |

**Not used at this grade:** Operationalisation as a formal requirement, the three rival accounts.

## How this grade is taught

Formal argument with sources. A student states the claim, the structure it rests on, and the cost of any modification proposed.

## How students show they have learned it

Written structural arguments, quarter quizzes and tests, four projects.

## Predicted misconceptions

### "The weights are real numbers in my head"

**Why it happens.** Students take the notation literally.

**How to fix it.** They are model parameters requiring empirical estimation.

**What to say.** "Nobody possesses a w2. Using them requires measurement."

### "A high-w3 description is a description of a person"

**Why it happens.** Weight cases read like personality types.

**How to fix it.** State the framing every single time weight cases appear.

**What to say.** "That is a structural description, not a person and not a diagnosis."

### "Closure is arbitrary strictness"

**Why it happens.** Refusing obviously relevant variables looks stubborn.

**How to fix it.** Run the cost argument.

**What to say.** "A framework that explains any result explains nothing."


## Support and extension

**More support.** Provide the relation on a desk card with each term labelled.

**Extension.** Ask them to propose a sixth variable and name what becomes unfalsifiable. Do not use extension to release later vocabulary.
