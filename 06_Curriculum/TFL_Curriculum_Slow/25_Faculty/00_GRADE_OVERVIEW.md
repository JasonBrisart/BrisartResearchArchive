# Faculty

**Course:** Institutional Stewardship · **Stage:** Faculty
**12 modules of 3-4 hours** · **Four quarters**

## What this year owns

Artifacts that work when you are not in the room, tested by blind execution.

> A student who overclaims made an error. A supervisor who permitted it made a larger one.

## Entry check — before session one

**Faculty assumes Postdoctoral.** The participant designs a hedged programme with real stop conditions.

- [ ] Distinguish structural programme failure from individual error
- [ ] Audit a programme for single-point dependency and repair it
- [ ] Specify a change log capable of detecting specification drift
- [ ] Write stop conditions that name observations with decision authorities

If a box will not tick, return to `../24_Postdoctoral/` and reteach that outcome before starting. Advancement follows demonstrated readiness, never the calendar.

## Exit outcomes

- Produce a disclosure protocol executable by somebody else
- Supervise without transferring career risk to the student
- Enforce scope through procedure rather than presence
- Pass blind execution on disclosure and scope enforcement

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **disclosure protocol** | where and how status is stated, and by whom |
| **hedged supervision** | structuring a student's work to survive refutation |
| **tiered enforcement** | structural prevention, interception, correction |
| **blind execution** | testing an artifact by having somebody else perform it |
| **derivative work** | work requiring rights beyond reading and studying |

**Not used at this grade:** Version authority, replication consortia, registries, retirement policy.

## How this grade is taught

Every artifact must be executable by a colleague who did not write it. This is tested by blind execution, not by reading.

## How students show they have learned it

Seven artifacts, blind-execution tests, a defended portfolio.

## Predicted misconceptions

### "Underclaiming is the safe direction"

**Why it happens.** Academic hedging defaults to dismissal.

**How to fix it.** Calling it a private model is as inaccurate as calling it established.

**What to say.** "This is the direction this room will get wrong."

### "Explaining the clinical boundary is enough"

**Why it happens.** It works in the room, so it feels sufficient.

**How to fix it.** Explaining does not scale and softens under pressure.

**What to say.** "You will hear it proposed again next week. Write the procedure."

### "Learning outcomes should state framework knowledge"

**Why it happens.** The course is about the framework.

**How to fix it.** Phrase outcomes as competences that survive refutation.

**What to say.** "Then it is a methods course using a live example."


## Support and extension

**More support.** Provide each template with one section fully worked, and pair every test.

**Extension.** Ask them to run blind execution on a colleague outside the cohort. Do not use extension to release later vocabulary.

## This grade is gated

The final does not pass unless both gate items are satisfied regardless of total
score: a falsification condition naming a possible observation, and a correctly
identified invalid application with its boundary named. Announce both in session
one; never apply them retroactively.
