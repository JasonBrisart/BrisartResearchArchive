## The pivot session of this quarter

**Session 22 — Final Revision.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Session 19:** every student names a conclusion they cannot draw
- **Session 20:** every portfolio contains all nine components
- **Session 21:** every student records their unanswered questions
- **Session 22:** every unanswered question from rehearsal is addressed
- **Session 23:** the executability gate is passed by external execution
- **Session 24:** every student compares first draft with final portfolio

## Errors to expect this quarter

| Session | Students will | Correct it by |
|---|---|---|
| 19 | list generic limitations | Press for the phenomenon: what specifically would this miss? |
| 20 | omit the feasibility statement | Check for it explicitly. |
| 21 | defend an instrument by restating its intent | Redirect: intent is not validity. |
| 22 | leave rehearsal questions unaddressed | Require one entry per unanswered question. |
| 23 | present a design requiring their presence | Run the blind execution before the presentation, always. |
| 24 | cannot find early drafts | One folder from Session 1. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
