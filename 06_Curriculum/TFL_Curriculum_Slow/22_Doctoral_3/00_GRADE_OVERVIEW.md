**Doctoral Year 3 assumes Doctoral Year 2.** The participant produces an original evidenced critique.

- [ ] Distinguish original critique from status objection and theory preference
- [ ] State a target so fairly that a proponent accepts the rendering

- [ ] Specify a closure path and give a proportionate assessment

If a box will not tick, return to `../21_Doctoral_2/` and reteach that outcome before starting. Advancement follows demonstrated readiness, never the calendar.

## Exit outcomes

- State the inference ceiling for a single study and justify the placement
- Write a reverse ladder and state whether a null fires the condition
- Produce a seven-section referee report with located findings
- Defend an adjudication proposal against four adversarial roles

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **inference ladder** | the graded set of claims a result licenses |
| **referee report** | a structured judgement to journal standard |
| **disclosure audit** | checking whether a manuscript represents status accurately |
| **adjudication proposal** | a design intended to move an open question |
| **triage verdict** | whether a proposal would move the question at all |

**Not used at this grade:** Governance instruments, supervision plans.

## How this grade is taught

The inference ceiling is declared in both directions. A verdict resting on the framework's status is a reviewer error and is penalised.

## How students show they have learned it

Referee reports, an adjudication proposal, calibration analysis.

## Predicted misconceptions

### "Rung four is reachable from one study"

**Why it happens.** Cumulative reasoning feels available immediately.

**How to fix it.** Rung four requires converging designs.

**What to say.** "Overclaiming is how frameworks get discredited."

### "Reviewer disagreement means one reviewer is wrong"

**Why it happens.** Divergence reads as error.

**How to fix it.** Calibrate. Divergence about standards is normal.

**What to say.** "Editors can see the difference between a standard and a reputation."

### "A proposal should test the framework"

**Why it happens.** The framework is the object of study.

**How to fix it.** Narrow it to one claim and its least-separable rival.

**What to say.** "Frameworks are not tested as wholes. Move one question."


## Support and extension

**More support.** Provide the ladder with rungs one to three worked and instructor specimens.

**Extension.** Ask for the editorial letter following three divergent reports. Do not use extension to release later vocabulary.

## This grade is gated

The final does not pass unless both gate items are satisfied regardless of total
score: a falsification condition naming a possible observation, and a correctly
identified invalid application with its boundary named. Announce both in session
one; never apply them retroactively.
