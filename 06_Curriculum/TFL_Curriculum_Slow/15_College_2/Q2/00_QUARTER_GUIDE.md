## The pivot session of this quarter

**Session 11 — Persistence And Sampling.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Session 8:** every student produces a genuine alternative explanation for a correlation
- **Session 9:** every instrument has a separate activation index
- **Session 10:** every student names three plausible alternatives per instrument
- **Session 11:** every student identifies a vulnerability in their own criterion
- **Session 12:** at least one marker returns zero questions
- **Session 13:** every student receives a question list from an external run
- **Session 14:** the class identifies its own weakest area

## Errors to expect this quarter

| Session | Students will | Correct it by |
|---|---|---|
| 8 | assert the instrument is clean | Run the three requirements line by line. |
| 9 | assume one measure captures both | Ask which of the two a given reading reflects. |
| 10 | name alternatives that could not plausibly apply | Ask for plausibility: would a reviewer raise that one? |
| 11 | omit the partial-match rule | Supply a borderline case and ask how it scores. |
| 12 | assume one clean run is enough | Require two independent markers. |
| 13 | resolve ambiguities silently | Require the record: if you inferred, that is a question. |
| 14 | review only recent sessions | Sample from every session. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
