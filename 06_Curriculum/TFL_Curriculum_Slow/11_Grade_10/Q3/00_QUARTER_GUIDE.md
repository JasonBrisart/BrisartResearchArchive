## The pivot lesson of this quarter

**Lesson 21 — Reporting The Result.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Lesson 17:** every student has a checklist with no item requiring clarification
- **Lesson 18:** every student receives a clarification list
- **Lesson 19:** the second run produces fewer questions than the first
- **Lesson 20:** every student has a dated, contemporaneous record
- **Lesson 21:** every results section is marked and cleaned
- **Lesson 22:** every student names a conclusion they cannot draw
- **Lesson 23:** every student answers a reproducibility question
- **Lesson 24:** the class identifies the missing element in at least four

## Errors to expect this quarter

| Lesson | Students will | Correct it by |
|---|---|---|
| 17 | write a method only they could run | Hand it to a classmate on the spot and list every question asked. |
| 18 | fill gaps silently using common sense | Require the record: if you guessed what they meant, that is a question. |
| 19 | defend the original wording | Point at the evidence: somebody asked. That is the evidence. |
| 20 | reconstruct the record afterwards | Check timestamps. Reconstructed records score partial. |
| 21 | defend interpretive phrasing as context | Cut it and show the section still reports. |
| 22 | list generic limitations | Press for specifics: name the phenomenon this would miss. |
| 23 | present the result without the blind spots | Ask for them in front of the room. |
| 24 | omit the outcome definition | Check it every time. It is the commonest omission. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
