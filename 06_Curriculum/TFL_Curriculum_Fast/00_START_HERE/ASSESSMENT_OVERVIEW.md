# Assessment Overview

How students are evaluated across all four bands.

## Assessment Philosophy

Three rules govern every assessment in this package.

**1. Prediction accuracy is never graded.** Students receive credit for recording predictions, reasoning about them, and analyzing outcomes. Never for being right. This is stated to students on day one of every band and is what makes honest reporting possible.

**2. Scope is assessed.** From Band C onward, students are tested on what TFL does *not* cover. Over-application is a scored error, not a harmless enthusiasm.

**3. The loop outranks the vocabulary.** A student who explains carry-forward in plain language but forgets a term scores higher than one who lists five terms without the cycle.

## What Each Band Assesses

| Band | Format | Graded work |
|---|---|---|
| A (K-2) | Oral and drawing | Observation checklist, loop drawing |
| B (3-5) | Written, short | 3 homework sets, 2 quizzes, unit task |
| C (6-8) | Written, analytic | 4 homework sets, 2 quizzes, unit test |
| D (9-12) | Formal | 5 homework sets, 3 quizzes, midterm, final |

## Band A — Observation Only

No written tests. Instructors complete a checklist per student:

- Names one thing noticed
- Names one thing remembered
- Names one thing expected
- Reports a surprise and what they expected instead
- Indicates that the cycle repeats

Drawing task: draw the loop with arrows. Scored complete or developing.

## Band B — Foundations

| Instrument | Weight |
|---|---|
| Homework sets (3) | 30% |
| Quiz 1 — components | 15% |
| Quiz 2 — carry-forward | 15% |
| Unit task — loop trace | 40% |

## Band C — Analysis

| Instrument | Weight |
|---|---|
| Homework sets (4) | 25% |
| Quiz 1 — variables | 10% |
| Quiz 2 — persistence and contradiction | 15% |
| Unit test | 50% |

Band C introduces the persistence-versus-accuracy item type, which appears on both the quiz and the test.

## Band D — Formal

| Instrument | Weight |
|---|---|
| Homework sets (5) | 20% |
| Quizzes (3) | 15% |
| Midterm — loop trace and structure | 25% |
| Final — study design, falsification, scope | 40% |

The Band D final requires students to state a falsification condition and to identify an invalid application. Both are required to pass the final regardless of other scores.

## Universal Rubric Dimensions

All written work across Bands B, C, and D is scored on four dimensions:

| Dimension | What it measures |
|---|---|
| Component accuracy | Are the five parts correctly identified? |
| Loop reasoning | Is carry-forward shown, not just implied? |
| Persistence reasoning | Is intensity correctly separated from accuracy? |
| Scope discipline | Does the student stay inside what TFL models? |

Detailed rubrics live in each band's `assessments/` folder.

## Re-Assessment

Students may revise and resubmit any homework set once. Quizzes and tests follow standard school policy.

The wrong-answer analysis in `STUDY_METHODS.md` (Method 7) is the recommended prerequisite for any resubmission.
