# Study Methods

Fifteen ways for students to study TFL. Different methods suit different learners, and instructors should offer several rather than prescribing one.

---

## Method 1 — The Loop Draw

**Best for:** Every band. Visual learners especially.

Draw the cycle from memory. Do not copy. Start with an empty circle and fill in what goes where.

Self-check: does your drawing show something leaving the cycle and re-entering it? If the arrows only go one direction with no return, you have drawn a line, not a loop.

Repeat daily until the drawing is identical two days in a row.

---

## Method 2 — The Surprise Journal

**Best for:** Bands B, C, D. Everyday practice.

Each day, record one surprise:

```
What surprised me:
What I must have been expecting:
Where that expectation came from:
Did it stay with me later? Yes / No
```

The third line is the valuable one. Tracing an expectation back to its source is memory retrieval made visible.

---

## Method 3 — The Five-Column Trace

**Best for:** Bands C and D.

Take a real event and fill a table:

| Window | `Input(t)` | `Minfo(t)` | `Sim(t)` | `E(t)` high/low | Persisted? |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

The rule that makes this useful: row 2's contents must connect to row 1's. If they don't, you have written three unrelated moments rather than a loop.

---

## Method 4 — Teach It to Someone Younger

**Best for:** All bands. Strongest retention method available.

Explain TFL to a younger sibling, a family member, or a student in a lower band, using only their vocabulary level.

If you cannot explain it without notation, you have memorized notation instead of the idea.

---

## Method 5 — The Prediction Interrupt

**Best for:** Bands B, C, D. Practice, not writing.

Several times a day, freeze before a routine action and ask: what do I expect in the next second?

Then check.

The goal is not accuracy. It is catching the prediction while it is still running.

---

## Method 6 — Boundary Sorting

**Best for:** Bands C and D. Directly assessed.

Make two columns: *inside the model* and *outside the model*. Sort ten real examples.

Reliable "outside" items: growing up, learning to read over years, a friendship changing, a culture's traditions, why consciousness exists, which brain cells fire.

If everything lands inside, you are over-applying the framework.

---

## Method 7 — Wrong-Answer Analysis

**Best for:** After any quiz or test.

For every item missed, write:

```
What I answered:
What the correct answer is:
Which idea I actually confused:
```

The third line matters most. Most errors trace to one of three confusions: persistence versus accuracy, the loop resetting versus carrying forward, or affect building versus gating the prediction.

---

## Method 8 — The Two-Minute Explanation

**Best for:** Bands C and D. Exam preparation.

Set a timer for two minutes. Explain the whole framework out loud without notes. Record it if possible.

Listen back and mark where you hesitated. Hesitation marks the gap.

---

## Method 9 — Equation Walking

**Best for:** Band D only.

Take the integration function and the persistence condition. For each symbol, say aloud what it is, what it does, and what changes if it increases.

```
F(t) = w1·Input(t) + w2·Minfo(t) + w3·Sim(t)
Sim(t+1) = Sim(t), if E(t) > θ_persistence
```

Critical check: can you explain why `E(t)` appears in the second relation and not the first? If not, review the persistence-gate distinction before anything else.

---

## Method 10 — Condition Prediction

**Best for:** Band D.

Given a parameter change, state the expected behavior before checking.

| If this changes | What happens? |
|---|---|
| `w1` rises | |
| `w2` rises | |
| `w3` rises | |
| `E(t)` falls below `θ_persistence` | |
| `θ_persistence` is lowered | |

---

## Method 11 — Partner Contradiction Drill

**Best for:** Bands C and D. Pairs.

One partner describes a scenario and stops before the outcome. The other states their prediction aloud. The first partner then gives an outcome that breaks it.

The second partner reports: did the broken prediction return when the scenario was repeated?

This makes recurrence observable in about ninety seconds.

---

## Method 12 — Flashcards, Built Correctly

**Best for:** Band C vocabulary.

Do not write "`Sim(t)` = predictive simulation" on a card. That tests translation, not understanding.

Write instead:

```
Front:  A student expects the bus at 7:45 because it always comes then.
        Which component is the 7:45 expectation?
Back:   Sim(t). The "always comes then" part is Minfo(t).
```

Every card should contain a scenario, not a definition.

---

## Method 13 — The Silent Loop

**Best for:** All bands. Two minutes.

Sit quietly and watch for a single prediction forming. Do not force one. Wait.

Most students find one within a minute: a sound they expect to continue, a person they expect to enter, a moment they expect to end.

This demonstrates Principle 2 — prediction runs whether or not you are trying.

---

## Method 14 — Rewrite the Definitions in Your Own Words

**Best for:** Bands C and D.

Take each component and write a definition that uses none of the original wording.

Then check: does your version still make clear that `E(t)` only controls persistence? That is the definition students most often flatten into "emotion affects everything."

---

## Method 15 — The Week Review

**Best for:** All bands. End of unit.

Answer five questions in writing:

1. What are the parts?
2. What is the loop?
3. What decides whether a prediction carries forward?
4. What does contradiction do?
5. What is this model *not* for?

A student who can answer all five has met the unit outcomes. Question 5 is not optional and is assessed in every band from C upward.
