# Pre-TFL Notes

This directory contains the raw, pre-formal notes that preceded the **Temporal Feedback Loop (TFL)** framework. These are not part of TFL itself — they are the informal exploratory thinking that came *before* TFL had a name, a structure, or any formal definition.

Nothing here should be treated as a specification, a claim, or a finished idea. It's the unfiltered record of noticing a pattern before understanding it.

## Why this is public

These notes are released as-is for transparency into how TFL originated. Labs and researchers studying TFL may find it useful to see the raw observations that the formal framework was later built to explain. This is a record of process, not a companion document to the framework — it should not be used to interpret, validate, or extend TFL itself.

## What's in here

| File | Content |
|---|---|
| `first_loop_idea.md` | The earliest attempt to describe the repeating pattern — input → memory → expectation → interpretation → back again — before knowing if it was metaphor or real structure. |
| `raw_thinking.md` | Unstructured first-pass observations: thoughts persisting, delayed updating, memory feeling automatic rather than chosen. |
| `early_structure_attempt.md` | A first attempt to break the loop into components (input, memory, expectation, emotional influence) without yet knowing how they connect or in what order. |
| `recurring_patterns.md` | A pass at naming the patterns that kept recurring across the notes — persistence, delayed updating, stepwise processing, multiple coexisting interpretations. |
| `weird_observations.md` | Specific, isolated oddities that didn't fit cleanly anywhere else — things feeling true after being known false, contradictions not deleting anything, fading vs. vanishing with no clear rule. |
| `reading_fragments.md` | Notes made while cross-referencing the observations against existing literature (predictive processing, constructive memory, interoceptive inference, mind-wandering/perceptual decoupling) to see if the pattern already had a name in the literature. |

## What this is not

- This is **not** documentation of TFL's actual mechanism, math, or implementation.
- This is **not** a curriculum, tutorial, or onboarding material.
- Nothing here is guaranteed to be accurate, final, or consistent with the released TFL framework — some ideas here were later dropped, revised, or contradicted as TFL was formalized.

For the actual TFL framework and its documentation, see the formal release materials elsewhere in the Brisart Research Archive.
