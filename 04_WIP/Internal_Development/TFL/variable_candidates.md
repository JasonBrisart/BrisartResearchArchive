# Historical Context

This document records variables proposed during internal development.

These variables were exploratory constructs intended to explain recurring observations, anomalies, or unresolved questions.

Purpose:

Candidate variables provided a mechanism for investigating whether observed patterns could be represented more formally.

Important Note:

A variable appearing in this document should not be interpreted as part of TFL.

Many candidate variables never advanced beyond exploratory consideration.

Historical Importance:

The document preserves possible directions that were considered during development, including those ultimately rejected.

Relationship To Released TFL:

Only variables appearing in the formal TFL documentation should be treated as authoritative framework components.

## State variables

- persistence_inertia — state variable representing lag between affect and simulation decay
- latent_simulation_state — subthreshold simulation persistence

## Parameters

- persistence_threshold — potential nonlinear gating function on E(t)
- cue_overlap — similarity-based parameter for reentry probability
- simulation_competition — parameter governing multi-simulation dynamics
- contradiction_gain — scaling factor for revision vs suppression
- belief_weight — parameter influencing retrieval and contradiction interpretation
- ambiguity_weight — dynamic adjustment of Input vs Sim influence
