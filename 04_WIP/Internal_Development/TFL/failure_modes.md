## Identification failures

- System fails when simulation content cannot be uniquely identified.
- System fails when multiple simulations cannot be resolved or tracked.

## Measurement failures

- System fails when affective intensity cannot be measured reliably.
- System fails if contradiction does not produce measurable update or suppression.

## Signal & noise failures

- System fails under extreme input noise where signal is indistinguishable.
- System fails if behavioral outputs do not correlate with simulation presence.

## Model comparison failures

- System fails when baseline models explain observed effects equally well.
