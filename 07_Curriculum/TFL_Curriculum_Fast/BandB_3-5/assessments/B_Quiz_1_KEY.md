# Band B — Quiz 1 ANSWER KEY

**Total: 10 points**

---

**1.** (3 points — 1 each)

```
Notice     — B  (What is coming in right now)
Remember   — C  (What comes back from before)
Expect     — A  (What I think happens next)
```

---

**2.** (3 points — 1 each, any order)

```
Notice / what I notice
Remember / what I remember
Expect / what I expect
```

Accept plain-language variations.

---

**3.** (1 point)

```
False
```

---

**4.** (1 point)

```
zero
```

Accept "nothing."

---

**5.** (2 points)

Full credit for any answer identifying **memory / having been there before** as the source.

Sample full-credit answers:
- "Because it's always noisy in the morning, so I remembered that."
- "From remembering other times I walked in."

**1 point:** Answer identifies an expectation exists but doesn't trace it to memory.

**0 points:** "I just knew."
