## Section 1 — The System (12 points)

**1.** (10 points — 2 each)

| Variable | Definition | Full credit requires |
|---|---|---|
| `Input(t)` | Sensory evidence available in the current window | Mentions sensory / incoming |
| `Minfo(t)` | Retrieved memory content active in the window | Mentions memory retrieval |
| `Sim(t)` | Predictive simulation; specific anticipated outcome | Mentions prediction with content |
| `E(t)` | Affective intensity; governs persistence only | **Must mention persistence** |
| `F(t)` | Integrated state; combined and carried forward | Mentions integration or carry-forward |

`E(t)` defined as "emotion" alone earns 1 of 2. The persistence function is the graded element.
