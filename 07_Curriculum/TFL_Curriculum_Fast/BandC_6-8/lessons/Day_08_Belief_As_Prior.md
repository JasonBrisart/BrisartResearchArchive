# Band C — Day 8: Belief as a Prior

**Duration:** 45 min
**Materials:** Chart paper

---

## Objective

Students understand `Belief(t)` as a stable structure that biases retrieval and simulation under ambiguity.

---

## 1. Hook — The Ambiguous Input (7 min)

Present something genuinely ambiguous — a partial image, an unclear sound, an incomplete sentence.

Students write what they think it is.

Collect the range of answers.

**Ask:**
> "Identical input. Why the spread?"

Steer toward: what each person already thought was likely.

---

## 2. Name — Belief as Constraint (12 min)

Write:

```
Belief(t)
An affectively stabilized structural prior
that constrains retrieval (Minfo(t)) and
simulation generation (Sim(t)) under ambiguity.
```

Unpack it:

- **Prior** — it was there before this moment
- **Stabilized** — it doesn't change window to window
- **Constrains** — it narrows what memory gets pulled and what predictions get built
- **Under ambiguity** — it matters most when input is unclear

Draw it:

```
Belief(t) ──constrains──→ Minfo(t)
Belief(t) ──constrains──→ Sim(t)
```

**Say:**
> "Note what it does *not* do. It doesn't replace input. It biases which memories come back and which predictions get built — and it does the most work when the input is unclear."

---

## 3. Work — Belief Tracing (16 min)

Students trace one ambiguous situation.

```
The ambiguous input:        _____________________

What I already believed:    _____________________

Which memory came back:     _____________________

The Sim(t) I built:         _____________________

Someone with a different belief would have expected:
                            _____________________
```

The last line is the analytical work.

---

## 4. Compare — Same Input, Different Priors (7 min)

Pair two students whose beliefs differed on the hook.

Walk both traces side by side.

**Say:**
> "Same `Input(t)`. Different `Belief(t)`. So different `Minfo(t)`, and a different `Sim(t)`. The input didn't decide it alone."

---

## 5. Carry (3 min)

**Say:**
> "Next: what the whole system looks like over time. There are three shapes it makes."

---

## Instructor Notes

- Keep beliefs low-stakes: beliefs about schedules, about how a game goes, about what teachers do.
- Do not solicit beliefs about identity, family, politics, or self-worth. See `SCOPE_AND_BOUNDARIES.md`.
- `Belief(t)` is a structural constraint across cycles rather than a dynamic core signal within each timestep. Say this if students ask why it is listed separately.
