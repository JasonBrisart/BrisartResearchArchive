# Micro-Lesson C4: Scope Sort

**Duration:** 6 minutes
**Band:** C (6-8)
**Materials:** Index cards (optional)

---

## Purpose

Practice rejecting out-of-scope applications.

## Script

Read claims. Students signal INSIDE or OUTSIDE.

| Claim | Answer |
|---|---|
| "Why I expected the door to be unlocked" | INSIDE |
| "Why I became interested in music over six years" | OUTSIDE |
| "Why that sudden noise startled me" | INSIDE |
| "Why my class acts differently on Fridays" | OUTSIDE (group-level) |
| "Why I still expected circle after the square" | INSIDE |
| "What consciousness actually is" | OUTSIDE |
| "Which brain cells did that" | OUTSIDE |
| "Why I thought the bus was late" | INSIDE |

## The Rule Students Should Derive

```
Short time-step + stateable prediction  → inside
Years, identity, groups, brain wiring,
   consciousness itself                 → outside
```

## Close

> "Being able to say 'that's outside this model' is understanding it better, not less."

## Use

Before the Band C unit test, where scope is directly scored.
