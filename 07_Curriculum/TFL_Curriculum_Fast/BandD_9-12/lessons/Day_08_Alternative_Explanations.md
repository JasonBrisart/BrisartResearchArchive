# Band D — Day 8: Alternative Explanations

**Duration:** 50 min

---

## Objective

Students articulate three competing accounts and explain what each predicts.

---

## 1. Hook — Explain This Without TFL (8 min)

Present a result:

> A student keeps expecting a cancelled event to happen. The expectation persists for three days despite contradicting information.

**Say:**
> "Explain that without using TFL."

Students will produce: uncertainty, stress, habit.

**Say:**
> "You just independently generated the three alternatives the framework has to be tested against."

---

## 2. Name — The Three Alternatives (14 min)

Write all three with their distinct predictions:

```
UNCERTAINTY-ONLY
  Persistence reflects unresolved ambiguity.
  Predicts: resolve the ambiguity → persistence ends,
  regardless of intensity.

AROUSAL-ONLY
  Persistence reflects general activation.
  Predicts: any high-arousal state produces
  persistence, regardless of specific content.

HABIT-BASED
  Persistence reflects repetition.
  Predicts: frequently repeated content persists,
  regardless of intensity or ambiguity.
```

**Then the TFL prediction:**

```
TFL
  Persistence reflects E(t) relative to θ_persistence,
  with identifiable simulation content.
  Predicts: content-identifiable simulations persist
  when intensity clears threshold — and this cannot be
  reduced to ambiguity, arousal, or repetition alone.
```

**Say:**
> "A valid implementation must be expressible in a form that permits adjudication against these accounts. That's a requirement, not a courtesy."

---

## 3. Work — Differential Predictions (18 min)

Students build the comparison table for one scenario.

| Account | Predicts persistence when... | Predicts no persistence when... |
|---|---|---|
| Uncertainty-only | | |
| Arousal-only | | |
| Habit-based | | |
| TFL | | |

Then:

> Identify one condition where TFL predicts something **different** from all three alternatives.

That condition is the seed of Day 9's design.

---

## 4. Compare — The Discriminating Condition (8 min)

Collect proposed discriminating conditions.

Strong candidates typically involve: low ambiguity + high intensity + novel content, which separates TFL from all three.

---

## 5. Carry (2 min)

**Say:**
> "Tomorrow you design the study that actually distinguishes them."
