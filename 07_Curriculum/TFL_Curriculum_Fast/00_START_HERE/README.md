# Temporal Feedback Loop (TFL) — K-12 Curriculum

A complete teaching package for the Temporal Feedback Loop framework, built for kindergarten through grade 12.

## What TFL Is

TFL describes how experience is updated in short repeating time steps of roughly 100 to 300 milliseconds. In each step, five things combine:

- Sensory input — what is perceived
- Memory — what is recalled
- Simulation — the predicted outcome
- Affect — emotional intensity
- The current state of experience

The result of each moment is carried forward and influences the next moment. That carry-forward is the loop.

## Reading Order for a New Instructor

1. `HOW_TO_TEACH_TFL.md`
2. `TEACHING_PRINCIPLES.md`
3. `SCOPE_AND_BOUNDARIES.md`
4. `COMMON_MISCONCEPTIONS.md`
5. `VOCABULARY.md`
6. Your band's `BAND_OVERVIEW.md`
7. `lessons/Day_01_*.md`

Budget about two hours for Bands A and B, three hours for Band C, four hours for Band D.

## Bands Are Independent

A school may teach one band, several bands, or the full sequence. Each band is self-contained and assumes no prior TFL instruction. Bands do build on each other when taught in sequence, and each `BAND_OVERVIEW.md` notes what carries forward.

## No Science Background Required

Instructors do not need training in neuroscience, psychology, or cognitive science. Every lesson plan includes the full script, the expected student responses, and the corrections for predictable wrong answers.
