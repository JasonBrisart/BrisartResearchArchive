# Accommodations and Differentiation

How to adjust TFL instruction without lowering the conceptual bar.

## Core Principle

TFL describes something every student already does constantly. The concept does not need simplifying. The *access route* does.

Differentiate the input and output format. Do not differentiate the idea.

## For Students Who Need More Support

**Reduce component count, not concept depth.**

Teach three parts instead of five: notice, expect, right now. Add memory and intensity only once the loop is secure. A student who understands carry-forward with three components has learned more than one who can list five without the cycle.

**Use physical movement.** Walk the loop as a floor path with labeled stations. Students physically carry an object from "right now" back to the start.

**Provide sentence frames.**

```
I noticed ______.
That made me remember ______.
So I expected ______.
Instead, ______ happened.
```

**Pre-load the surprise.** Some students find engineered mismatch stressful. Tell them privately in advance that something will be different today. Prediction still runs; only the startle is removed.

## For Students Who Need Extension

**Move them up a band's notation** while keeping their band's activities.

**Assign the adjudication question early.** Ask a Band C student to argue that a classroom result is better explained by habit than by the model. This is Band D content and it engages advanced students without adding busywork.

**Have them build assessment items.** Writing a good persistence-versus-accuracy question requires a firmer grasp than answering one.

**Boundary hunting.** Challenge them to find three examples the framework does *not* cover and defend each. Over-application is the common failure mode for advanced students specifically.

## Language Support

The five components map to concrete everyday words in any language. Translate the student-facing names, not the notation:

- Notice, remember, expect, matters, right now

Keep `Input(t)`, `Sim(t)`, and the rest in original form once introduced, and let the translated plain-language name carry the meaning.

Diagram-first instruction works especially well here. The loop drawing requires no text.

## Reduced Writing Load

Every written task in this package has an oral equivalent:

| Written task | Oral equivalent |
|---|---|
| Five-column trace | Verbal walk-through, instructor records |
| Surprise journal | Recorded audio or partner interview |
| Scope analysis | Sorting physical cards into two piles |
| Study design | Explain the design aloud to a partner |

Scoring uses the same rubric dimensions.

## Attention and Session Length

Micro-lessons exist for this reason. Any main lesson can be split into two micro-lessons across two days without losing the arc.

The only structural requirement: never separate a Hook from its Name step. The experience and its label must occur in the same session.

## Sensory Considerations

Several activities use sound-based mismatch. Visual and tactile substitutions are provided in each lesson plan under **Variations**. A prediction can be broken in any modality.

## What Not to Accommodate

Do not exempt students from the scope boundary content. Knowing what TFL does not model is a core outcome for Bands C and D, and it is the content most directly tied to using the framework responsibly.

Do not grade any student on prediction accuracy as an accommodation. The rule is universal.
