# How Homework Works

## One file per session, none compulsory

Homework exists for every session. You decide each time whether to set it.
Skipping carries no penalty.

If you set homework less often than every session, prioritise:

| Priority | Set after |
|---|---|
| 1 | The pivot session of the quarter (named in each quarter guide) |
| 2 | Any session that released new vocabulary |
| 3 | The session before an assessment |
| 4 | Everything else |

## The same four parts at every grade

| Part | What it is |
|---|---|
| **Recall** | The previous session's closing sentence, from memory |
| **The task** | The session's work, independently, on new material |
| **Explain** | Tell somebody absent; record the question they could not answer |
| **Carry forward** | The session's closing sentence, reproduced from memory |

Pre-K does all four aloud in five minutes with an adult. A doctoral seminar writes
paragraphs. The structure never changes, which is what makes grade transitions
feel continuous.

## Marking

| Element | Points |
|---|---|
| Attempted and handed in | 2 |
| Written before the outcome was known, where that applies | 1 |
| Reasoning shown rather than asserted | 2 |

One revision and resubmission permitted.

## Scored as a percentage of what you set

Never of what exists. A class set six homeworks and a class set twenty are on the
same scale. Skipping never penalises a student.
