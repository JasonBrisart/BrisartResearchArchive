# Student Activities — Field Stewardship

Reusable work for this grade. These are **not** copies of the lesson printouts.
They exist for practice, review, reteaching, extension, make-up work, independent
study, substitute cover, and portfolio building.

## What is here

| File | Use it for | Needs a teacher? |
|---|---|---|
| `Vocabulary_Practice.md` | Retrieval of this grade's released terms | No |
| `Independent_Practice.md` | Extra examples of the grade's core outcome | No |
| `Partner_Activities.md` | Paired explanation and comparison | No |
| `Reteaching_Activities.md` | Recovery when a check fails | Yes |
| `Extension_Activities.md` | Depth for students ahead of the sequence | No |
| `Review_Games.md` | End-of-quarter whole-class review | Yes |
| `Reflection_Journal.md` | Portfolio reflections | No |
| `Portfolio_Guide.md` | What to keep and why | No |

## Rules for every activity here

- It rehearses, applies, or extends a **named grade outcome**. Nothing here is
  busywork.
- It uses only vocabulary released at or before this grade. Not: Nothing is withheld. This is the terminal level.
- It never scores prediction accuracy.
- It never asks a student to alter a result to match an expected pattern.

## This grade's outcomes

1. Identify which field-level functions currently have no owner
2. Establish version authority without claiming authority over the specification
3. Specify a registry making prespecification verifiable and nulls recoverable
4. Pass blind adoption on version authority and retirement

Every activity in this folder supports at least one of those.
