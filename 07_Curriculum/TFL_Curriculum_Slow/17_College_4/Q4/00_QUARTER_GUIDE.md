## The pivot session of this quarter

**Session 25 — The Degree In Review.** If you set homework only once this
quarter, set it after this one. If you are short of time, cut anything before
cutting this.

## Do not move on until

- **Session 22:** both gates are satisfied and all four roles answered
- **Session 23:** every critique contains all six sections
- **Session 24:** every plan names an actionable first step
- **Session 25:** every student compares across all four years
- **Session 26:** every student knows whether they would pass the gates
- **Session 27:** every student has worked on the gates if they failed them
- **Session 28:** both gates are satisfied

## Errors to expect this quarter

| Session | Students will | Correct it by |
|---|---|---|
| 22 | present advocacy before the condition | Stop it: condition first. Start again. |
| 23 | omit the anticipated defence | Return it unmarked: what is the best the framework can say? |
| 24 | write an unactionable wish list | Require the first step to be doable in a month. |
| 25 | cannot find early work | One folder per year, from Year 1 Session 1. |
| 26 | ignore the gate items | Mark the gates first. |
| 27 | review what they already know | Prioritise any failed gate above everything else. |
| 28 | run out of time before the gate items | Instruct them to answer the gate items first. |

## Honest data rule

If a classroom activity does not produce the expected pattern, preserve the
result. Do not re-run it to get a tidier outcome, and do not change any student's
classification. Ask instead whether the method could have detected the pattern at
all, and record the answer. A result that does not fit is a result.
