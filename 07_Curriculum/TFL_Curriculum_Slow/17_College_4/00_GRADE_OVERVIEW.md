## Entry check — before session one

**College Year 4 assumes College Year 3.** The student adjudicates against field-specific rivals.

- [ ] Show that a consistent result discriminates nothing
- [ ] State a rival in a form its proponents accept, externally checked
- [ ] Settle the redundancy charge with a differential prediction
- [ ] State results that would favour each account, including the rivals

If a box will not tick, return to `../16_College_3/` and reteach that outcome before starting. Advancement follows demonstrated readiness, never the calendar.

## Exit outcomes

- Place falsification before advocacy without exception
- Write a falsification condition with a demonstrated firing pathway
- State the inference ceiling for both positive and null results
- Defend a capstone against rival, measurement, inference, and scope challengers

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **inference ceiling** | the highest claim a design licenses |
| **reverse ladder** | what a null result does and does not license |
| **capstone** | an independent defended piece of work |
| **overclaiming** | asserting more than the design supports |
| **exploratory** | analysis not prespecified, and labelled as such |

**Not used at this grade:** Referee-quality manuscript review, governance instruments.

## How this grade is taught

A falsification condition is required before any advocacy is accepted. The inference ceiling is declared for both positive and null results.

## How students show they have learned it

A capstone, an independent critique, problem sets, midterm and gated final.

## Predicted misconceptions

### "Rung three is too conservative"

**Why it happens.** Cumulative reasoning is how fields progress.

**How to fix it.** Run the argument both ways.

**What to say.** "Overclaiming on a framework's behalf is how frameworks get discredited."

### "A null result refutes the framework"

**Why it happens.** Symmetry with the positive case.

**How to fix it.** The reverse ladder.

**What to say.** "Your condition fires only if prespecified and its controls held."

### "Prespecification prevents discovery"

**Why it happens.** Rigidity reads as a constraint on finding things.

**How to fix it.** Exploration is legitimate and must be labelled.

**What to say.** "The problem is presenting exploration as confirmation."


## Support and extension

**More support.** Provide the inference ladder with rungs one to three worked.

**Extension.** Ask for the discussion section a null result would license. Do not use extension to release later vocabulary.

## This grade is gated

The final does not pass unless both gate items are satisfied regardless of total
score: a falsification condition naming a possible observation, and a correctly
identified invalid application with its boundary named. Announce both in session
one; never apply them retroactively.
