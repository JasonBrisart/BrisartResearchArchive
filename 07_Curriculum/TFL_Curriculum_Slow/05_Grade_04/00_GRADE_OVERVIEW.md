# Grade 4

**Course:** Carry Forward · **Stage:** Intermediate
**32 lessons of 40 minutes** · **Four quarters**

## What this year owns

Carry-forward. The hardest idea in the primary years.

> Nothing starts from zero. Each moment begins with what the last one handed it.

## Entry check — before session one

**Grade 4 assumes Grade 3.** The student builds a supported five-line reconstruction of one moment.

- [ ] State that the three parts combine into one experienced moment
- [ ] Build a five-line reconstruction ending in a single combined statement
- [ ] Decompose a described moment into three parts that check forwards
- [ ] Support each line with evidence and mark unsupported lines honestly

If a box will not tick, return to `../04_Grade_03/` and reteach that outcome before starting. Advancement follows demonstrated readiness, never the calendar.

## Exit outcomes

- State that nothing starts from zero and explain what that means
- Produce an eight-row trace with specific inheritance in every row
- Distinguish a row that is wrong from a row that is broken
- Repair a break by adding inheritance or a missing moment

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **carry forward** | the moment you just had becomes the start of the next |
| **inherit** | what the new moment receives from the one before it |
| **chain** | a run of moments each beginning from the one before |

**Not used at this grade:** All variable names, persistence threshold, integration.

## How this grade is taught

Multi-step written explanation. Reasoning shown at each step, not implied. A trace must demonstrate inheritance across several moments.

## How students show they have learned it

Written traces, quarter quizzes and tests, four projects.

## Predicted misconceptions

### "The loop starts over each time"

**Why it happens.** Cycles are usually taught as resets.

**How to fix it.** The purple elephant demonstration, then the passing chain.

**What to say.** "Nothing starts from zero."

### "Carrying forward means remembering on purpose"

**Why it happens.** The chain activity is deliberate, so students generalise the effort.

**How to fix it.** Contrast the effortful chain with the automatic version.

**What to say.** "Normally it happens without you doing anything."

### "A trace is four good descriptions in a row"

**Why it happens.** Each moment is well written, so the work looks complete.

**How to fix it.** Cover every column but the inheritance one and ask what remains.

**What to say.** "The inheritance is the trace."


## Support and extension

**More support.** Use the physical object chain rather than written traces.

**Extension.** Ask for the longest honest chain, with the point where it fades marked. Do not use extension to release later vocabulary.
