**Course:** Naming The System · **Stage:** Middle

## Exit outcomes

- Name and define all five declared variables
- State that E(t) gates persistence and does not build the prediction
- Give the window length and distinguish update rate from content duration
- Apply the identifiability rule to accept or reject a Sim(t)

## Vocabulary released this year

| Term | Meaning |
|---|---|
| **Input(t)** | sensory evidence available in the current window |
| **Minfo(t)** | retrieved memory content active in the window |
| **Sim(t)** | the predictive simulation; the specific expected outcome |
| **E(t)** | affective intensity; governs carry-over only |
| **F(t)** | the integrated state, carried forward as a prior |
| **temporal window** | one processing step, roughly 100 to 300 milliseconds |
| **persistence** | a simulation continuing into the next window |

**Not used at this grade:** The integration function, the persistence threshold, w1/w2/w3, theta.

## How this grade is taught

Formal vocabulary required. Claims stated with the correct term. A student may no longer say 'the expecting part' once notation is released.

## How students show they have learned it

Written mapping work, quarter quizzes and tests, four projects.

## Predicted misconceptions

### "100 to 300 ms is how long a thought lasts"

**Why it happens.** Conflating the update cycle with the duration of content.

**How to fix it.** Compare with frame rate. A film updates many times a second.

**What to say.** "That is how often the system updates, not how long an idea lasts."

### "Emotion makes the prediction"

**Why it happens.** Students assume the strongest-feeling element is the driver.

**How to fix it.** State the constraint early and repeat it every session.

**What to say.** "It decides whether the prediction survives, not what it is."

### "A feeling counts as a simulation"

**Why it happens.** 'I had a bad feeling' sounds like a prediction.

**How to fix it.** Apply the identifiability test.

**What to say.** "If you cannot say what you expected, this model does not cover it."


## Support and extension

**More support.** Provide a desk card with the five variables and their plain equivalents.

**Extension.** Ask them to estimate how many windows a lesson contains. Do not use extension to release later vocabulary.
