# Temporal Feedback Loop (TFL)

## Architecture (v2 Draft)

### Core Architecture

TFL models consciousness as a recursive, emotionally modulated loop operating across short temporal frames. Each loop frame integrates present input, retrieved memory, emotional weighting, and recursive evaluation to generate an updated output that influences the next frame.

### Elementary Frame Structure

Each frame processes:

1. **`Input(t)`**: Current sensory or internal perceptual input.
2. **`Minfo(t)`**: Context-sensitive memory retrieval.
3. **`E(t)`**: Emotional modulation of selection, interpretation, and persistence.
4. **`F`**: Recursive integration / predictive evaluation.
5. **`Output(t)`**: Attentional, behavioral, or interpretive output.

The output of one frame contributes to the input conditions of the next frame.

### Formal Loop Expression

The loop can be minimally represented as:

```text
Output(t) = F[Input(t), Minfo(t), E(t)]
```

Where:

- **`F`** is a dynamic recursive integrator.
- **`E(t)`** biases retrieval, interpretation, and persistence.
- **`Output(t)`** contributes to the next cycle's state conditions.

This architecture is recursive rather than linear.

### Processing Sequence Per Frame

At each temporal frame:

1. Current input is received.
2. Relevant memory fragments are retrieved.
3. Emotional salience weights available content.
4. Recursive integration evaluates and simulates likely outcomes.
5. Output is generated.
6. Output influences attention, interpretation, and future loop state.

This process repeats continuously across overlapping frames.

### Recursive Feedback Structure

The loop does not merely move forward. It can re-enter itself by revisiting and reinterpreting recent moments. This recursive re-entry helps explain:

- Postdictive reinterpretation
- Self-editing memory
- Delayed action generation
- Recursive correction of active simulations

Later loop states can therefore reshape the meaning of earlier inputs.

### Emotional Modulation Layer

`E(t)` functions as a core regulatory layer in the architecture.

`E(t)` determines:

- Which memories are recalled
- Which simulations enter or persist in the loop
- Which perceived inputs become dominant
- Whether output stabilizes, drifts, or re-enters

Emotion is therefore not added after processing. It operates within the core loop itself.

### Delay and Carry-Forward

A defining property of the architecture is temporal delay.

Simulations and intentions may be encoded in one frame and only expressed behaviorally in later frames once:

- Emotional coherence is sufficient
- Contextual alignment emerges
- Recursive output converges

Output is therefore not always immediate and may remain latent before expression.

### Role and Identity Layer

As the loop repeats across time, simulations encode implicit role structures. These roles can stabilize through repeated emotionally coherent activation and feedback convergence.

This produces:

- Recurrent role patterns
- Identity stabilization
- Role saturation
- Possible role conflict or inversion under disconfirmation

Identity, in this architecture, is a recursively stabilized simulation pattern rather than a fixed entity.

### Failure / Instability Modes

The architecture allows several instability outcomes when feedback is mismatched or unresolved:

- **Stabilization**: Simulation is reinforced.
- **Loop Drift**: Simulation weakens but remains unresolved.
- **Loop Inversion**: Simulation flips role structure.
- **Residual Echo**: Simulation collapses partially but later re-enters.

These are architecture-level outcomes of recursive feedback under varying emotional and contextual conditions.
