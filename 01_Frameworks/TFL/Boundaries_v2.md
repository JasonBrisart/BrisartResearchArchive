# Temporal Feedback Loop (TFL) Boundaries

The Temporal Feedback Loop (TFL) is a local, mechanistic framework describing short-timescale integration of sensory evidence, memory retrieval, **affective persistence constraints**, and predictive simulation. The following boundaries define the limits of its claims and prevent overextension beyond its intended scope.

## 1. Scope of Applicability

TFL is defined to model only moment-level integration processes operating over brief temporal windows. It is not defined to model:

- Long-term memory consolidation
- Identity formation
- Narrative construction
- Developmental trajectories
- Group-level or social-level dynamics

These require separate frameworks.

## 2. Not a Neural Implementation

TFL is not defined to specify:

- Exact neural circuits
- Anatomical substrates
- Neurotransmitter systems
- Laminar pathways
- Oscillatory signatures

Any neural references are illustrative and do not constitute architectural commitments.

## 3. Not a Theory of Consciousness

TFL does not claim to explain:

- What consciousness is
- How subjective experience arises
- Why awareness exists
- Any metaphysical or ontological account of mind

It specifies a functional integration model, not a theory of phenomenology.

## 4. Not a Complete Cognitive Architecture

TFL is a constrained component within a broader cognitive system. It does not replace or subsume:

- Decision-making frameworks
- Attentional control systems
- Emotional regulation models
- Long-range predictive architectures
- Narrative or identity-level frameworks

TFL interacts with these systems but is not defined to model them.

## 5. Not a Behavioral or Clinical Model

TFL is not defined to provide:

- Diagnostic criteria
- Therapeutic mechanisms
- Behavioral predictions outside its defined temporal window
- Explanations of psychopathology

Any correspondence with clinical phenomena is conceptual and does not constitute a validated application.

## 6. Assumption-Bound Validity

TFL is valid only under the following assumptions:

- Processing occurs in discrete temporal windows
- Simulation content is identifiable
- Affective intensity governing persistence is measurable
- Sensory and contextual inputs remain sufficiently stable within a window

If these assumptions fail, such as under chaotic input conditions, absence of identifiable simulation content, or extreme physiological disruption, TFL predictions are not guaranteed to hold.

### 6.1 Testability Constraint

TFL applies only in contexts where all core variables can be operationalized and measured. Any use of the framework without observable mapping of `Input(t)`, `Minfo(t)`, `E(t)`, `Sim(t)`, and `F(t)` does not constitute a valid application or test of TFL.

## 7. No Claims of Agency or Intentionality

TFL does not attribute:

- Agency
- Volition
- Goals
- Selfhood

To any internal process. Simulations are treated as computational hypotheses, not intentions or actions.

## 8. Variable Closure Constraint

All valid inferences are restricted to the explicitly defined variables:

- Sensory evidence (`Input(t)`)
- Retrieved memory content (`Minfo(t)`)
- Affective intensity governing persistence (`E(t)`)
- Predictive simulation (`Sim(t)`)
- Integrated internal state (`F(t)`)

No additional constructs, latent processes, or external variables are assumed or inferred beyond this set.

## 9. No Claims of Exclusivity

TFL does not claim to be:

- The only valid model of temporal integration
- A universal explanation for spontaneous thought
- A replacement for predictive coding, active inference, or related frameworks

It is a specific, falsifiable module within a broader theoretical architecture.
